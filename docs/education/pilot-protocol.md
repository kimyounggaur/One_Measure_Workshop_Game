# 소규모 관찰 계획 — 미실시

목적은 5명 정도의 탐색적 사용성 관찰로 조작·문구 문제를 찾는 것이다. 효과 연구나 통계적 교육효과 입증이 아니다. 실제 모집·세션·촬영·녹음은 하지 않았다. 미성년자 모집·촬영·민감정보 수집은 별도 승인 전 실행하지 않는다.

1. 목적·중단 가능성을 설명하고 별도 동의를 확인한다. 음악 경험은 선택적이고 상세 개인정보는 수집하지 않는다.
2. 무음 또는 소리 시작, 첫 조각, L1을 도움 없이 관찰한다.
3. L3 빈칸/쉼, L4 길이/시작 횟수, L6 듣기/시각 대안 선택의 이유를 묻는다.
4. T5–T8은 색/격자 도움 없이 수행한다. 설명은 자기 확인 또는 사람 검토이며 AI 자동 점수는 없다.
5. 결과 해석, 저장·재방문·JSON 백업을 관찰한다.
6. 관찰자의 도움·경로·중단 원인을 기록하되 낮은 운동 수행이나 읽기/환경 문제를 능력 부족으로 분류하지 않는다.
