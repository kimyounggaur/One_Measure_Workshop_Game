# 알려진 범위와 제한

- 한국어, 4/4 한 마디, 8분 격자, MIDI60 한 음색만 제공한다. 제품 UI/import에서 3/4·6/8·붙임줄·점음표·셋잇단·16분음표·다성부를 허용하지 않는다. 미래 박자 계산의 단위 테스트는 제품 지원 선언이 아니다.
- 터치 단계 선택·목록·키보드를 지원하며 드래그는 구현하지 않았다. 좁은 폭에서 긴 버튼 문구는 여러 줄이 될 수 있다. 실제 물리 기기·OS 확대·VoiceOver/TalkBack 시험은 남아 있다.
- Web Audio는 사용자 시작 동작이 필요하다. 시스템 무음/스피커/이어폰 출력을 앱이 완전히 확인하지 못한다. OfflineAudioContext 파형 성공은 사람이 소리를 들었다는 뜻이 아니다.
- 탭 결과는 선택적 연습이다. 물리 지연·청음 능력·운동 능력·교육효과를 측정/보장하지 않는다. 무보정·fallback은 낮은 신뢰도를 표시하고, 불안정 입력·중단은 무효 처리한다. 무선 출력 변경은 다시 확인해야 한다.
- 작품20개, 선택 진단 기록20개, 파일1MiB, 문서8이벤트 제한이 있다. 자동 슬롯 삭제는 없다. 사용자 export가 장기 보존 수단이며 계정/클라우드 동기화가 없다.
- 새로고침 직후 이전 writer lease가 남아 읽기 전용일 수 있다. 명시 인수 또는 만료가 필요하다. 저장 불가/손상 시 메모리 초안과 이전 정상본의 한계가 있으며 모든 손상을 복구할 수 없다. 미래 DB를 이 앱으로 강제 downgrade하지 않는다.
- 오프라인은 최초 온라인 준비가 완료된 뒤 가능하다. 브라우저 저장 회수, 최초 미접속, 업데이트 자산 실패를 항상 극복하는 기능은 아니다. 새 버전 적용은 저장 성공과 사용자 동작을 요구한다.
- 7일 선택 재확인은 기기 날짜를 사용한다. 세션 중 시각 불일치/뒤로 간 날짜를 확인하지만, 서로 다른 방문 사이 시스템 날짜 변경을 완벽히 탐지하지 못한다. 이를 실패/망각 판정에 쓰지 않는다.
- 실제 음악교육 검수, 물리 기기/출력·보조기술, 파일럿·학습효과 관찰, 운영자 정책 확인은 미실시다. 확인된 자동 검사 미해결 P0/P1은0이며 정식 출시 수용은 보류한다.
