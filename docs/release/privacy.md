# 기록과 개인정보 안내

작품 제목/리듬, 초안, 이론 진도, 힌트·해답·시각 대안 경로, 선택 전이 응답과 자기 확인, 화면 설정, 입력 맞춤 profile은 이 브라우저의 IndexedDB에 저장한다. 앱 계정이나 기기 간 자동 동기화는 없다. 삭제/초기화와 브라우저의 공간 회수로 없어질 수 있어 JSON 백업을 권한다.

직접 치기의 원시 입력 시각과 matching 상세는 실행 중 메모리에만 둔다. 결과 닫기/세션 종료 시 버리며 DB/백업에 넣지 않는다. 저장되는 입력 맞춤은 offset·clockMode·sampleRate·날짜·사용자가 고른 출력 분류이며 원시 표본이 아니다. 제목·자유 문장은 HTML로 실행하지 않는다. import 파일의 URL을 fetch하지 않는다.

백업은 사용자가 다운로드/선택한 JSON 파일이다. 파일 자체에 제목·응답·진도가 포함될 수 있으므로 사용자가 원하는 장소에 보관한다. 보관함에서 작품 삭제 또는 별도 확인을 거친 전체 기록 삭제를 할 수 있다. 원본 제공 문서·개발용 예시는 실제 학습자의 기록이 아니다.

앱 코드에는 로그인·원격 학습 분석·광고·외부 글꼴·마이크·카메라·위치 접근이 없다. 실제 Chrome/Edge의 연습→닫기→저장→백업 경로에서 외부 네트워크 요청0, 비GET0, capture0, beacon0, 쿠키0, DB/백업 원시 입력 키0을 확인했다. 정적 파일 다운로드는 당연히 사이트 호스트에 요청한다. 이 결과는 모든 브라우저 확장이나 호스팅의 내부 운영을 감사했다는 뜻이 아니다.

호스팅은 사용자 승인 범위의 별도 Vercel 프로젝트다. 앱의 학습 데이터 전송과 호스팅의 접속 처리는 다르다. Vercel은 고객 사이트 트래픽의 IP·IP 기반 대략적 위치·시스템 구성 정보를 처리한다고 [개인정보 고지](https://vercel.com/legal/privacy-notice)에 설명한다(2026-10-19 확인). [Runtime Logs 문서](https://vercel.com/docs/logs/runtime)는 요금제별 보존 차이를 설명하지만, 이 정적 사이트의 모든 CDN/보안 로그 보존기간과 동일하다고 단정할 수 없다.

이 작업에서는 분석 SDK·log drain·추가 유료 관찰 기능을 켜지 않는다. 프로젝트의 정확한 보존기간·접근자·대상 학습자·운영자 문의 경로는 책임자가 확인해야 하며 정식 출시 수용에서 미확정으로 남는다. 일반 Vercel 고지만으로 운영자의 안내를 대신했다고 주장하지 않는다.
