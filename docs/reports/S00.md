## 입력과 증거

직접 읽은 파일:

| 파일 | SHA-256 |
| --- | --- |
| task-3/source-design.md | 32B0D081B1C8AE74B19E7555AB08187BA859660D813B19C411F1279B0FDDE597 |
| task-3/source-prompts.md | 3513B480C8B1C11E8CC30D56E7E965A7F307AFCC715A324CC66A8F51E5F255B3 |

UTF-8 원문을 분할해 설계1–27장, 프롬프트0–31장 전체를 읽었다. 최초 출력의 콘솔 인코딩 문제는 Console.OutputEncoding=UTF8로 수정한 뒤 재열람했다. 원본 파일을 변환/수정하지 않았다.

환경 조사 명령: Get-ChildItem -Force(루트와 game), Get-Command node/npm/git, 상위 AGENTS.md 존재검사, node --version, npm.cmd --version, git --version, git -C game status --short --branch, Get-FileHash -Algorithm SHA256(원문2개). 실행 PowerShell. Node v24.14.0/npm11.9.0/Git2.55.0.windows.3. `git status`는 저장소가 없어 fatal(예상 상태)이었고 전체 조사 스크립트는 exit0이었다. Git 검사 성공 또는 기존 저장소 보존 검증으로 포장하지 않는다.

기존 코드 광역 조사와 지정 GitHub empty 결과는 부모가 제공한 증거이며 본 문서 담당이 직접 수행한 검사가 아니다. 이번 직접 조사로 새 폴더 내 package/lockfile/README/소스 없음과 적용 AGENTS 없음이 확인되었다.
