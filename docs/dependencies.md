# 의존성과 출처

2026-10-19 공식 문서 및 npm registry의 안정 버전과 Node engine 확인. 실제 버전은 package.json과 package-lock.json이 권위다.

- React / React DOM (MIT): https://react.dev/
- Vite (MIT): https://vite.dev/guide/ — Node 20.19+ 또는 22.12+, 사용 Node24.
- TypeScript (Apache-2.0): https://www.typescriptlang.org/
- Vitest (MIT): https://vitest.dev/guide/ — 설치 버전 Node22.12/24/26 호환.
- Playwright (Apache-2.0): https://playwright.dev/docs/intro
- ESLint (MIT): https://eslint.org/ ; typescript-eslint (MIT): https://typescript-eslint.io/
- fake-indexeddb (Apache-2.0): https://github.com/dumbmatter/fakeIndexedDB
- axe-core (MPL-2.0): https://github.com/dequelabs/axe-core
- @types/* (MIT): https://github.com/DefinitelyTyped/DefinitelyTyped

분석 SDK, 외부 폰트, 서버 계정, 광고, 결제를 추가하지 않았다. 사용자 제공 에셋의 출처 고지는 ASSET_NOTICES.md에 보존한다.
