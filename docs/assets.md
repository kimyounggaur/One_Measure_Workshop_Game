# 에셋 기록

원본 manifest1.0.0의 205개 이미지 전체를 [asset-manifest.json](asset-manifest.json)에 보존했다. 경로별 author/source/license/note/hash는 원문 레코드이며 [원문 출처 고지](ASSET_NOTICES.md)와 함께 읽는다. 현재 사용 파일은 public/assets의 동일 상대 경로에 있다. 원본 백업을 수정하지 않았다.

SVG200개는 이 프로젝트를 위해 작성된 벡터이며 직접 수정 가능하다는 원문 기록이 있다. PNG3/WebP2도 같은 manifest에 명시되어 있다. AI 배경은 장식 전용이며 기보 근거로 쓰지 않는다. 검수 프리뷰의 글꼴은 배포하지 않는다. 앱은 시스템 글꼴과 직접 합성한 단음/클릭만 사용한다. 외부 게임·음원 추출물을 추가하지 않았다.

8개 notation의 기호/분수/PPQ/이름과 온쉼표(기준선 아래)/2분쉼표(위) 방향은 [검사표](qa/asset-audit.md) 참조. 파일 hash205개/기호 XML 검사 통과와 사람 음악교육 검수 미실시를 구분한다. 앱 ‘도움말 · 화면 설정 · 출처’에서 원문 고지를 읽을 수 있다. React/React DOM19.3.1 및 scheduler0.28.0(MIT)의 실제 설치 LICENSE 원문은 THIRD_PARTY_NOTICES.txt와 public/THIRD_PARTY_NOTICES.txt에 보존하며 배포/오프라인에 포함한다. 앱 자체 권리자를 임의로 확정하지 않는다.
