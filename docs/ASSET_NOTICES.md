# 출처와 사용 안내

버전 1.0 · 2026-10-19

## 직접 제작한 벡터

- 대상: notation, controls, patterns, tiles, overlays, badges, app-icon 및 SVG에서 출력한 설치 PNG.
- 제작: OpenAI assistant가 이 프로젝트를 위해 새로 작성한 기하·벡터 경로. 외부 아이콘 팩이나 음악 글꼴의 경로를 복사하지 않았습니다.
- 원본: 각 SVG와 `sources/build_assets.py`.
- 수정: SVG와 제작 스크립트를 직접 편집할 수 있습니다. 사용자 프로젝트에 통합·크기 조정·색 변경이 가능하도록 원본을 포함했습니다.
- 외부 자산 라이선스: 해당 없음. 제3자 게임 캐릭터·스크린샷·곡·추출 파일은 사용하지 않았습니다.

## 생성한 장식 배경

- 대상: workshop-background-master.png와 두 WebP 출력.
- 제작: OpenAI 내장 imagegen 도구, 2026-10-19. 구체 모델명이 도구 반환에 없으므로 임의로 기재하지 않습니다.
- 생성 프롬프트: `sources/image-generation.json`에 실제 사용 문구 보존.
- 후처리: 원본 픽셀의 비례 축소와 WebP 인코딩. 악보·텍스트·로고 합성 없음.
- 사용: 요청자의 프로젝트용 산출물입니다. 서비스 이용 조건과 적용 법률을 따르며, 독점성·상표 적합성·저작권 등록 가능성을 보증하는 자료는 아닙니다. 제3자 소유 그림을 복제하도록 요청하지 않았습니다.
- 통합 시 배경은 장식 전용으로 취급하고 alt는 빈 값으로 제공합니다.

## 글꼴

- 런타임 SVG에는 글꼴 파일이나 텍스트 path가 필요하지 않습니다. UI 문구는 시스템 한글 글꼴을 사용합니다.
- 검수용 PNG의 한글 라벨에는 실행 환경에 설치된 Noto Sans CJK를 사용했습니다. 글꼴 파일 자체는 이 세트에 배포하지 않습니다.
- 검수 미리보기의 라벨은 런타임 버튼/설명 텍스트를 대신하지 않습니다.

## 앱 고지 화면에 넣을 수 있는 문장

“한 마디 조립실의 기호·아이콘·개념 도장은 본 프로젝트용으로 제작한 벡터입니다. 장식 공방 배경에는 AI로 생성한 원본 이미지를 사용했습니다. 음악 기호는 장식 이미지와 독립된 검수용 SVG로 제공됩니다.”

이는 외부 라이선스가 의무화한 문구가 아니라 출처를 명확히 하는 선택적 고지 초안입니다. 앱 자체의 저작권 주체·연도·사용 조건은 실제 프로젝트 책임자가 확정하세요.
